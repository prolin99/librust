# 📚 LibRust 現代化單機圖書管理系統

[![Rust](https://img.shields.io/badge/language-Rust-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/license-MIT%20%2F%20Apache-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%20(x64)-brightgreen.svg)]()
[![Version](https://img.shields.io/badge/version-0.4%20版-blueviolet.svg)]()

一套為中小學校、圖書館、研究室、基金會及私人藏書量身打造的**高效能單機版圖書管理系統**。全程式以 **Rust** 語言深度開發，封裝為**單一綠色免安裝執行檔 (`圖書管理系統.exe`)**，體積僅約 8 MB。無需安裝 Python、Node.js、IIS、SQL Server 等任何複雜環境，開箱雙擊即用！

---

## ✨ 系統核心亮點

- 🚀 **極致輕量、雙擊即開**：內嵌 Axum 高效非同步後端與自包含 SQLite 資料庫，零外部依賴。
- 📦 **100% 綠色單機架構**：所有資料庫檔案（`library.db`）與封面圖片均儲存在程式本機目錄，離線亦可安全順暢運作。
- 🔍 **首創五層智慧 ISBN 書目抓取引擎**：整合台灣本土最權威的「金石堂網路書店」與「三民書局」，全面支援最新 `978-626`、`978-957`、`978-986` 等正體中文圖書，一鍵自動補全書名、作者、出版社、出版年、繁體大圖封面與書籍摘要。
- 🛡️ **健全的流通業務防護**：讀者有逾期圖書時自動禁止借閱新書；歸還圖書自動精確計算逾期天數；借書時即時列出目前在借清單並支援快捷歸還/續借。
- 🖨️ **條碼標籤與借書證批次列印**：支援 Code 39 條碼生成、自訂毫米（mm）貼紙尺寸、自選列印範圍，背標（書脊標籤）支援大字分類號與存放位置排版。
- 📁 **相容傳統舊系統資料庫**：內建舊版[林朝敏--簡易圖書管理系統2.*](https://blog.syps.tn.edu.tw/modules/tad_web/page.php?WebID=1&PageID=3) 格式轉換器，舊有書目與讀者檔案無痛一鍵升級。

## 🛠️ 功能詳細介紹

### 1. 🔄 借還櫃台（流通作業）
- **條碼掃描槍支援**：輸入框自動聚焦，刷入條碼按下 Enter 立即完成流通作業。
- **讀者在借清單檢視**：刷入讀者證號後，立即展開該讀者目前在借書單（條碼、書名、應還日、狀態），並提供「續借」與「歸還」快捷按鈕。
- **逾期嚴格防護**：讀者若有逾期未還圖書，系統自動彈出警示並**鎖定書籍刷入框與借書按鈕**，徹底防杜違規超借。
- **還書逾期天數計算**：歸還時若有逾期，系統自動計算逾期天數，並在提示框與記錄備註中標註 `⚠️ 逾期歸還 X 天`。

### 2. 📋 在借與催還管理
- **即時狀態過濾**：下拉選單支援「全部出借中」、「⚠️ 僅看逾期 (催還名單)」、「✅ 正常借閱中 (未逾期)」。
- **快速關鍵字搜尋**：即時搜尋讀者姓名、證號、書名或書籍條碼。
- **完整多筆分頁導航**：可自由選擇每頁顯示筆數（10 筆、20 筆、50 筆、100 筆或全部顯示），提供「首頁 / 上一頁 / 下一頁 / 末頁」快速導航。

### 3. 📖 書籍管理與批次匯入
- **書籍維護**：支援書名、ISBN、作者、出版社、分類號、存放位置、定價、內容簡介等維護。
- **智慧自動給號**：新增書籍時自動建議下一個書籍條碼/登錄號（支援自訂流水號）。
- **Excel / CSV 批次匯入**：一鍵下載標準書籍 CSV 範本，支援大批書籍一次性整批匯入入庫。
- **五層網路書目補齊**：
  1. **金石堂網路書店 (Kingstone)**：覆蓋台灣最新正體中文出版品，命中率極高，抓取繁體高解析封面大圖。
  2. **三民書局 (Sanmin)**：老牌圖書通路互補，支援學術、政府出版品與本土書籍。
  3. **WorldCat (OCLC)**：世界聯合圖書館目錄。
  4. **Google Books**：國際中文書目優先查詢。
  5. **Open Library**：開放圖書館來源，若遇到漢語拼音音譯（如 `Man hua San guo zhi`）系統自動調用智慧還原引擎轉回正體中文《漫畫三國志》。

### 4. 👥 讀者管理與身分權限
- **讀者資料維護**：姓名、身分別、班級、年級、電話、Email、備註。
- **讀者自動給號**：新增讀者時自動推算下一組讀者證號。
- **身分規則配置**：可為不同身分別（如學生、教職員、志工）設定各自的可借冊數上限、可借天數、續借天數。
- **批次匯入**：支援 Excel / CSV 讀者批次名冊匯入，方便開學季學生批次建檔。

### 5. 🖨️ 借書證與條碼標籤列印
- **精確貼紙規格套用**：可在設定中自訂貼紙標籤的寬度與高度（mm），精準匹配各廠牌標籤印表機。
- **彈性列印範圍**：支援輸入起始編號、結束編號、關鍵字/身分別篩選，亦可設定最多列印筆數限制。
- **書籍條碼與背標選項**：
  - 勾選「書籍標籤包含背標」時，左側產生清晰的書脊分類標籤（大字粗體分類號、存放櫃號位置），右側為書名、條碼與館名。
  - 取消勾選時自動切換為純書籍條碼貼紙。
- **讀者借書證列印**：正反面排版設計，正面包含條碼、姓名、證號、身分班級。

### 6. 📊 統計儀表板
- **即時數據卡**：總藏書量、在館可借、目前借出、逾期未還統計。
- **熱門借閱排行 Top 8**：即時統計借閱次數最高的熱門借閱榜單。
- **藏書分類分佈圖**：依分類號自動計算藏書比例與長條圖分佈。
- **最近歸還有逾期之歷史紀錄**：列出最近 10 筆已歸還但逾期的借閱歷史（讀者、借閱書名、借書日期、應還日期、歸還日期、逾期天數）。

### 7. ⚙️ 系統設定與舊系統無縫升級
- **基本資料**：圖書館名稱、電話、地址、借書規則等。
- **舊版 DBF 一鍵轉入**：若有舊版[林朝敏--簡易圖書管理系統2.*](https://blog.syps.tn.edu.tw/modules/tad_web/page.php?WebID=1&PageID=3)之 DBF 檔案（`DBF01.DBF`, `Dbf02.DBF`, `Dbf03.DBF`, `Liborrow.DBF`等），放入 `/data` 資料夾後啟動，系統自動轉換匯入歷史藏書、讀者及在借記錄。

## 🚀 下載與安裝說明

### 方法一：直接使用 Release 執行檔（推薦，免安裝）

1. 前往 GitHub Repository 的 **Releases** 頁面。
2. 下載最新版本的 `圖書管理系統.exe`(LibRust.exe)。
3. 將 `圖書管理系統.exe` 放置於您希望建立圖書館系統的目錄中（例如 `D:\圖書管理系統\`）。
4. **雙擊執行 `圖書管理系統.exe`**，程式會自動：
   - 在同目錄下建立 `library.db`（SQLite 資料庫）。
   - 自動開啟預設瀏覽器進入系統操作主頁面（預設網址為 `http://localhost:3000`）。
5. 即可開始新增讀者、建檔書籍或進行借還書作業！

> 💡 **資料備份提示**：如需備份系統，只需備份執行檔目錄下的 `library.db` 及 `covers/` 資料夾即可，搬遷電腦時整份資料夾複製過去即可正常使用。

## 🏗️ 專案技術架構

```
D:\antig\Library\
├── Cargo.toml            # Rust 套件依賴設定
├── src/
│   ├── main.rs           # 系統主入口、自動開啟瀏覽器與 Web 伺服器啟動
│   ├── models.rs         # 資料結構定義（書籍、讀者、流通、統計摘要）
│   ├── db.rs             # SQLite 資料庫操作核心、流通邏輯與單元測試
│   ├── api.rs            # RESTful API 端點路由 (Axum)
│   ├── frontend.rs       # 內嵌單一 HTML/CSS/JS 單頁應用介面 (SPA)
│   ├── enricher.rs       # 五層網路書目補齊與 ISBN 爬蟲引擎
│   ├── importer.rs       # Excel / CSV 批次匯入轉換器
│   └── legacy.rs         # 舊系統 Clipper / FoxPro DBF 讀取解析器
├── covers/               # 書籍封面圖檔本地儲存目錄
└── library.db            # SQLite 本機資料庫 (啟動後自動產生)
```

- **後端引擎**：[Rust](https://www.rust-lang.org/) + [Axum 0.7](https://github.com/tokio-rs/axum) (基於 Tokio 非同步 Runtime)
- **資料儲存**：[rusqlite](https://github.com/rusqlite/rusqlite) (SQLite3 內嵌封裝，支援 WAL 高併發模式)
- **網路通訊**：[reqwest](https://github.com/seanmonstar/reqwest) (非同步 HTTP 客戶端，附帶 TLS 安全連線)
- **前端介面**：現代化原生 HTML5 / CSS3 / JavaScript (無肥大外部前端打包依賴，極速響應)

## ❓ 常見問題 (FAQ)

**Q1：換新電腦時，如何將原有書籍和讀者資料搬移？**
> **A1：** 請先關閉系統，將程式所在資料夾內的所有檔案（主要是 `library.db` 與 `covers/` 目錄）複製到新電腦，在新電腦直接執行 `圖書管理系統.exe` 即可完整繼承所有資料。

**Q2：可以多台電腦同時連線使用嗎？**
> **A2：** 可以！系統已具備登入身分認證與 bcrypt 加密密碼保護機制。在同一區網（LAN/Wi-Fi）下的其他電腦或平板，只需在瀏覽器輸入主機的 IP 位址與連接埠（例如 `http://192.168.1.100:3000`），登入帳號密碼後即可同時操作借還書。（初次進入預設帳號與密碼均為 `admin`，登入後可於系統設定頁變更密碼）

**Q3：條碼掃描槍需要特別設定嗎？**
> **A3：** 本系統相容市面上 99% 以上的 USB / 藍牙條碼掃描槍（模擬鍵盤輸入模式 HID）。只要掃描槍結尾帶有 Enter 鍵功能即可自動觸發借還書。
